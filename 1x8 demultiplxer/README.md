# 1x8 Demultiplexer in Verilog This project implements a 1x8 Demultiplexer using Verilog HDL. A demultiplexer routes a single input to one of eight outputs based on the select signals. ## Truth Table | S2 | S1 | S0 | Active Output | |----|----|----|---------------| | 0 | 0 | 0 | Y0 | | 0 | 0 | 1 | Y1 | | 0 | 1 | 0 | Y2 | | 0 | 1 | 1 | Y3 | | 1 | 0 | 0 | Y4 | | 1 | 0 | 1 | Y5 | | 1 | 1 | 0 | Y6 | | 1 | 1 | 1 | Y7 | When input `D = 1`, the selected output becomes `1` and all other outputs remain `0`. ## Files - `demux_1x8.v` – Verilog source code - `demux_1x8_tb.v` – Testbench - `simulation_output.txt` – Simulation results - `README.md` – Project documentation ## How to Run Using ModelSim or any Verilog simulator: 1. Compile the files 2. Run the testbench 3. View the waveform or console output
